# Futuristic Sounds (Android)

फ्यूचरिस्टिक कंप्यूटर वाले साउंड: टच, नोटिफिकेशन पैनल, ऐप खोलना, स्वाइप, स्क्रॉल, ज़ूम, बैक, होम, रिसेंट।
हर इवेंट के लिए कस्टम साउंड और वॉल्यूम कंट्रोल।

## GitHub से APK बनाने के स्टेप
1. github.com पर नया Repository बनाएँ।
2. ZIP को extract करें और अंदर की सारी फाइलें/फोल्डर (`.github` फोल्डर समेत) repo में upload करें।
3. Repo > Actions टैब > "Build APK" > Run workflow (या upload के बाद अपने-आप चलेगा)।
4. 4-6 मिनट बाद रन खोलें > नीचे Artifacts > `FuturisticSounds-APK` डाउनलोड करें।
5. ZIP से `app-debug.apk` निकालकर फोन में install करें।

## फोन में चालू करना
1. ऐप खोलें > "Accessibility सेटिंग्स खोलें" > Futuristic Sounds > चालू करें।
2. Android 13+ पर: सेटिंग्स > ऐप्स > Futuristic Sounds > ⋮ > Allow restricted settings।
